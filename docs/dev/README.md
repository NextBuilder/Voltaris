## Repository layout

| Path | What it is |
|---|---|
| `crates/voltaris` | The MCP server binary and installer |
| `crates/voltaris-core` | Tools, router, checks and the MCP handler |
| `crates/voltaris-ipc` | Client for KiCad's IPC API |
| `crates/voltaris-sexp` | KiCad file parser and writer |
| `crates/voltaris-schematic-editor` | Typed schematic editor with lossless round-trips |
| `crates/voltaris-render` | Image rendering and pixel diffs for visual review |
| `crates/voltaris-vcs` | Git-based design checkpoints |
| `crates/schematic-viewer` | Desktop schematic viewer (Tauri) |
| `crates/voltaris/assets` | Skills and agents shipped to Claude |
| `kicad-plugin` | KiCad action plugin that starts the server |
| `claude-plugin` | Claude plugin, generated by `packaging/build-claude-plugin.py` |
| `packaging` | Release packaging: KiCad PCM, Claude plugin, MCPB |
| `xtask` | Repo checks (`cargo xtask`) |

Issue numbers such as `#408` in these notes refer to the upstream
[Konnect](https://github.com/mixelpixx/Konnect) tracker, where that work began.
